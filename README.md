It is a horror game where the player is in a dark asylum maze and have to find 4 glowing fuses, then reach the EXIT door at the far corner. The Patient hunts the player by sight and by sound.
I made this game in the VSCode.
I used AI but just to correct some errors and some movement related issues.
This game is very similar to Granny, but our motive is a bit different....
I used AI just to correct some errors and to smoothen the movement.
This game took almost 3 hours to code, I tracked the time using Hackatime extension.
At first I created a folder and inside it, I created a file"index.html", where i coded for many hours, and finally I was satisfied with my efforts!
